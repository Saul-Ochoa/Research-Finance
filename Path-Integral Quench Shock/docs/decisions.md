# Decision log

Every design decision in this project is recorded here, in chronological order. Entries are
**append-only**: a decision that is later reversed is not edited. A new entry supersedes it and
references the old ID.

## Governance rules

1. **Design decision → new row in this file.** This includes data choices, model choices,
   thresholds, scope cuts and naming conventions that affect results.
2. **Finding → new entry in [`model_behavior.md`](model_behavior.md)** (what the model does) or in
   **[`limitations.md`](limitations.md)** (what the study cannot claim).
3. **Parameter version change → new row here + the previous YAML archived in `config/archive/`.**
   `scripts/calibrate_params.py` archives automatically and refuses to reuse a version number.
   Frozen parameters are never edited in place; see D-010.
4. **Docs never lag the code.** A change to the code without the matching doc update counts as
   high-priority technical debt and is fixed before any new feature work.
